Covfefe or Coolidge?

One quote. Four presidents. Who said it?

About

Covfefe or Coolidge? is a guessing game. You read a real presidential quote and pick who said it from four portraits. About half the quotes are Donald Trump's, and the rest come from other presidents.

The game is built on the contrast between them. It's satire, but every word in it is real.

How quotes are checked

  • Every quote is checked word for word against a primary source: a transcript, video, archived post or letter.
  • After each answer, the game shows the date, a line of context and a link to the source, so you can check it yourself.
  • Quotes are short excerpts. The context line says where and when each one was said.
  • Only quotes that have been checked appear in the game.

Sources include the American Presidency Project (UC Santa Barbara), Roll Call Factba.se, the Miller Center (University of Virginia) and the Trump Twitter Archive.

Found a mistake?

If a quote's wording, date, president, context or source is wrong, please report it on GitHub (free account needed). You can also use the "Report a problem" link under any answer in the game, which fills in which quote it is. Mistakes get fixed, and every report and fix stays public.

How the game works

  • Daily: 10 quotes, the same for everyone, with a new set at midnight your time.
  • Practice: 10 random quotes, as often as you like.

Privacy

No accounts, no cookies, no ads. Visits and game events are counted anonymously with Plausible, which doesn't track individuals. Your daily results are stored only in your own browser. Fonts are loaded from Google Fonts, and the site is hosted on GitHub Pages.
